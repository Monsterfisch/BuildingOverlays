# Building Overlays

**作者**：Monsterfish
**版本**：1.0.0

在建筑上方绘制额外贴图。原版游戏本身就用这种机制处理塔楼垛口：贴图遮住走道以免单位看起来站在塔外，并在单位登塔时消失。本模块允许你只需把 PNG 放入 `overlays` 文件夹，即可为更多建筑添加或替换此类覆盖贴图。

## 大型城门楼

空置的大型城门楼会在塔楼上方显示覆盖贴图（分别对应入口朝向左下与右下两种朝向）；有部队登上时自动隐藏。可在设置中关闭。

## 主堡入口

修复原版贴图错误：在两个地图朝向上，主堡入口中部会出现与两侧塔楼不符的错误明暗光照。开启后与两侧塔楼一致。可在设置中关闭。

## 建筑上的部队

只要有单位站在建筑上，覆盖层就会隐藏——领主除外，否则常驻主堡的领主会永久隐藏主堡覆盖层。开启「仅当鼠标悬停在建筑上时隐藏覆盖层」后，塔楼、城门楼和主堡无论是否站人都保持城垛显示，仅在鼠标指向时隐藏（覆盖本模块贴图与游戏塔顶）。带 `units = "any"` 的覆盖层始终绘制。

## 前方建筑遮挡覆盖层

原版整块在建筑前角绘制覆盖层，会穿透紧邻的塔楼和城墙。本模块改为按地块条带绘制本模块与游戏自带覆盖层，使前方物体正常遮挡。可在设置中关闭（「允许前方建筑遮挡覆盖层」）。

## 在游戏中移动覆盖层

选中任意建筑，面板左侧列出其覆盖层（本模块贴图及游戏自带「Game #n」）。点击选中后建筑上会显示品红边框，右侧出现蓝色方向箭头（「Step」切换 1、5、20 像素），再次点击结束选择。「Save」会将每个覆盖层的位置写入游戏 `ucp` 文件夹中的一个文件，此后本模块将使用这些位置；该文件采用插件 `overlays.lua` 的格式。可在设置中关闭。

## 添加或修改贴图

将 PNG 放入 `overlays` 文件夹（透明区域保持透明），并在 `overlay_list.lua` 中描述对应建筑、入口朝向、是否有部队及位置偏移。

## 供插件调用

插件可自带覆盖层：将 PNG 与 `overlays.lua` 放入插件的 `resources/modsupport/building-overlays/` 目录，并在插件的 `enable` 中调用：

    local overlays = modules["building-overlays"]
    if overlays ~= nil then
      overlays:registerOverlaySource("ucp/plugins/MyPlugin-*/resources/modsupport/building-overlays/")
    end

同名覆盖层会替换本模块默认贴图。Save 按钮同样会将该插件的覆盖层位置写入 `ucp` 文件夹；插件自身的 `overlays.lua` 保持原样。

同一个文件也可以移动游戏自带的贴图，即面板中列为「Game #n」的那些。
