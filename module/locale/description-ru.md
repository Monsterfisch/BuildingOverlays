# Building Overlays

**Автор**: Monsterfish

Отрисовывает дополнительные накладки поверх зданий. Сама игра делает это для зубцов на башнях: изображение закрывает площадку, чтобы бойцы не казались стоящими снаружи, и исчезает, когда на башне есть войска. Этот модуль позволяет добавлять и заменять такие накладки для других зданий, просто помещая PNG-файлы в папку `overlays`.
