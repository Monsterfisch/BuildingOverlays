# Building Overlays

**Автор**: Monsterfish

Отрисовывает дополнительные накладки поверх зданий. Сама игра делает это для зубцов на башнях: изображение закрывает площадку, чтобы бойцы не казались стоящими снаружи, и исчезает, когда на башне есть войска. Этот модуль добавляет такие накладки другим зданиям: PNG из `overlay_list.lua` или из `overlays.lua` плагина. Инструмент накладок на панели здания выравнивает их и сохраняет положение.
