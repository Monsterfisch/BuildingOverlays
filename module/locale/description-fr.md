# Building Overlays

**Auteur** : Monsterfish

Dessine des images supplémentaires par-dessus les bâtiments. Le jeu le fait lui-même pour les créneaux des tours : une image couvre le chemin de ronde afin que les unités ne semblent pas flotter dehors, et disparaît lorsqu'il y a des unités dessus. Ce module ajoute de tels calques à d'autres bâtiments : PNG listés dans `overlay_list.lua` ou le `overlays.lua` d'un plugin. L'outil de calques du panneau du bâtiment les aligne et enregistre leur position.
