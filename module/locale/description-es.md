# Building Overlays

**Autor**: Monsterfish

Dibuja imágenes adicionales sobre los edificios. El juego ya hace esto con las almenas de las torres: una imagen cubre la pasarela para que las unidades no parezcan fuera de la torre y desaparece cuando hay unidades encima. Este módulo añade estas imágenes a otros edificios: PNG listados en `overlay_list.lua` o en el `overlays.lua` de un plugin. La herramienta de superposiciones del panel del edificio las alinea y guarda sus posiciones.
