# Building Overlays

**Autor**: Monsterfish

Zeichnet zusätzliche Grafiken über Gebäude. Das Spiel macht dies selbst für Turmzinnen: ein Bild, das den Wehrgang verdeckt, sodass Einheiten nicht vor dem Turm zu stehen scheinen, und das verschwindet, sobald Einheiten darauf stehen. Dieses Modul ergänzt solche Grafiken für weitere Gebäude: PNGs aus `overlay_list.lua` oder der `overlays.lua` eines Plugins. Das Overlay-Werkzeug im Gebäudefenster richtet sie aus und speichert ihre Positionen.
