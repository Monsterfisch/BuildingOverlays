# Building Overlays

**Szerző**: Monsterfish

További fedőképeket rajzol az épületek fölé. Maga a játék is így rajzolja a tornyok pártázatát: egy kép eltakarja a gyilokjárót, hogy az egységek ne tűnjenek a tornyon kívül állónak, és eltűnik, amikor katonák állnak rajta. Ez a modul más épületekre is tesz ilyen képeket: az `overlay_list.lua` vagy egy plugin `overlays.lua` fájljában felsorolt PNG-ket. Az épületpanel fedőkép-eszköze a helyükre igazítja és menti őket.
